# Daily Study Guide: Overview

## How This Works

This guide tells you exactly what to do every day for 12 weeks. No decisions
required — just follow the plan.

**Structure**: 6 days per week. Day 7 is rest or catch-up.

**Time**: ~2 hours per day (12-14 hours per week).

**Files**:

- `07_daily_guide_overview.md` — You are here. Start here.
- `08_daily_month1.md` — Weeks 1-4: Foundations
- `09_daily_month2.md` — Weeks 5-8: Architecture
- `10_daily_month3.md` — Weeks 9-12: Staff Impact + Capstone

## Rules

1. **Do not skip days.** If you miss a day, do it the next day. Do not jump ahead.
2. **Time-box exercises.** If you are stuck on a problem for more than the
   allotted time, read the hints, then read the solution, then re-implement
   from memory. Understanding > stubbornness.
3. **Write everything down.** Keep a journal (physical notebook or text file).
   Each day has a "Journal" prompt — answer it in 1-3 sentences.
4. **Read actively.** When a guide says "Read section X", take notes. Write
   down what surprises you or what you disagree with.
5. **Run the code.** When the guide says to run a command, actually run it.
   Do not just read the output.

## Daily Session Template

Every day follows this rhythm:

```
[0:00 - 0:05]  Review: Glance at yesterday's journal entry
[0:05 - 0:45]  Study: Read the assigned material (take notes)
[0:45 - 1:45]  Practice: Complete the assigned exercises
[1:45 - 2:00]  Journal: Answer the day's journal prompt
```

Some days are heavier on reading, some on practice. The time estimates are
per-activity and noted next to each item.

## Prerequisites

Before starting Day 1:

1. Verify Python 3.12+ is installed: `python --version`
2. Navigate to the project: `cd C:/temp/algorithms_gaps_analysis`
3. Generate all solution templates: `python main.py --generate`
4. Open this folder in your code editor (VS Code recommended)
5. Create a journal file: create `journal.md` in this folder

You are ready. Open `08_daily_month1.md` and begin.
