A DFA is exactly a synchronous Moore/Mealy machine with input alphabet Σ. NFA = “parallel speculation” of which state you might be in — subset construction materializes that powerset.

Context-free grammars

Productions like S → ( S ) | S S | ε generate matched parentheses. Parse trees / leftmost derivations. Pushdown automata add a stack — same nesting power as CFGs.

Why "context-free"?

A production A → α may fire regardless of surrounding symbols — the “context” doesn’t constrain the rewrite (unlike context-sensitive grammars).

Decidability sketch

Turing machines = unlimited tape + finite control. The halting problem is undecidable: no algorithm correctly answers “does program P halt on x?” for all P,x. Reduction is the main weapon: if A reduces to B and A is undecidable, B is too.

Complexity: P, NP, NP-complete

  • P: decidable in deterministic poly time.
  • NP: “yes” answers have poly-time checkable certificates.
  • NP-complete: in NP, and every NP problem reduces to it in poly time.

Staff-level takeaway

Recognize NP-hard flavors in product work (scheduling, exact covering). Reach for approximations, ILP, or constrained instances — don’t invent O(2ⁿ) “clever” searches for n=10⁵.
