Implementation Memory Games

Burn the idiomatic, theoretically clean implementation of each pattern into long-term memory. Once that base is automatic, you adjust it for the exact problem — you do not invent under pressure.

How this differs from Practice Arena

Arena trains adapting a pattern to a novel problem. These games train recalling the perfect base until typing it is muscle memory. Sequence: Memory Lab movie → these games → Practice Arena.

How to play

Choose a mode

  • Mastery Map — tiles for all 21 patterns plus core sorting / engineering idioms. Color = mastery 0–5. Click a tile, then pick a game from the ladder.
  • Daily Workout — auto-picks your 3 weakest templates and runs Cloze → Line order → Type from blank. No choices; just play.
  • Free Play — pick any template and any game from the dropdowns, then Start.

Game 1 — Mantra recite

  1. Read the pattern name (cover the mantra if it was visible).
  2. Say the one-sentence idiom aloud, then type it in the box.
  3. Click Check. Keyword overlap is enough (you don’t need a perfect quote).
  4. Use Show mantra only after you’ve attempted once.

Goal: the trigger phrase (“expand right, shrink left…”) fires instantly when you see the pattern name.

Game 2 — Cloze (key lines)

  1. Each prompt is a code line with ___ where a critical fragment belongs (conditions, mid formula, heap ops, etc.).
  2. Type the missing fragment exactly (spacing mostly ignored).
  3. Click Grade. You need about 80% of blanks correct.
  4. Wrong answers reveal the canonical fragment under the form.

Goal: the “dangerous” tokens are automatic — off-by-ones live here.

Game 3 — Line order

  1. You see the idiomatic lines shuffled.
  2. Click one line, then click another to swap them; or use ↑ / ↓.
  3. Restore the true top-to-bottom sequence of the canonical drill.
  4. Click Check order. Only a perfect sequence counts.

Goal: muscle memory of what comes before what (mark visited before enqueue, save nxt before rewire, …).

Game 4 — Type from blank

  1. Clear the editor. Recite the mantra once.
  2. Type the full idiomatic implementation from memory. Comments/docstrings are optional and ignored in grading.
  3. Optional aids: Hint: first lines, Show triggers, or Peek 3s (flashes the canonical code briefly).
  4. Click Compare to canonical. Structural match ≥85% passes; ≥98% is needed (with a bug hunt) for mastery 5/5.
  5. Read the line diff: ✓ match, ≠ your line, → expected line.
  6. Reveal + reset shows the answer — then clear and type again without looking.

Goal: the clean base is typeable under interview pressure. Arena work is then “tweak this,” not “invent this.”

Game 5 — Bug hunt

  1. Read the buggy near-miss (classic pitfall for that pattern).
  2. Find the mistake mentally, then type the corrected idiomatic version in the editor.
  3. Click Check fix (≥80% structural match to the fix).
  4. Stuck? Show explanation names the pitfall and shows the clean code — then retry from blank next session.

Goal: you recognize the failure mode before you ship it.

Mastery scoring

  • 1 — mantra or cloze started
  • 2 — cloze solid
  • 3 — line order perfect
  • 4 — type ≥85% (and ≥98% keeps you at 4 until bug hunt)
  • 5 — type ≥98% and a clean bug hunt

Progress is stored in browser localStorage (offline). Failed type drills can drop mastery by one — stay honest.

Daily rule

Run Daily Workout (3 weak templates) or lock one pattern to 5/5. Then solve 1–2 problems in the Practice Arena by adjusting the base you just recalled — never starting from a blank mental model.
