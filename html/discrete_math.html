Discrete Mathematics

The language of CS arguments. EE background helps (Boolean algebra, graphs); this track fills proofs, counting, and recurrence gaps.

EE bridge

Karnaugh maps and Boolean algebra → propositional logic. Netlists → graphs. Recurrence relations → same habit as solving linear DEs, but discrete.

Logic

Propositions, connectives, implications. Key rewrite rules: De Morgan, contrapositive P→Q ≡ ¬Q→¬P.

Truth table: implication P → Q

Proof techniques

  • Direct: assume P, derive Q.
  • Contradiction: assume ¬claim, derive absurdity.
  • Induction: base + step. Write P(n) explicitly.
  • Invariant: true before loop; preserved; conclude at exit — see Provability.
Worked: sum 1..n = n(n+1)/2 by induction

Base n=1: 1=1. Assume for k. Then 1..k+1 = k(k+1)/2 + (k+1) = (k+1)(k+2)/2.

Sets, relations, functions

Equivalence relations partition a set. Bijections preserve cardinality. Functions: injective / surjective / bijective.

Counting

Permutations P(n,k)=n!/(n-k)!. Combinations C(n,k). Pigeonhole: if n+1 items in n holes, some hole has ≥2.

Practice question

How many 5-card poker hands from 52? C(52,5). Order of dealing does not matter — divide out 5!.

Recurrences

Master theorem intuition: compare f(n) to n^{log_b a}. Unroll recursion trees; sum work per level. 

T(n) = 2 T(n/2) + O(n)  →  O(n log n)   (merge sort shape)
T(n) = T(n-1) + O(n)    →  O(n²)
T(n) = 2 T(n-1) + O(1)  →  O(2^n)

Graph theory basics

Degree sum = 2|E|. Trees: |E|=|V|-1, unique path. Bipartite ↔ no odd cycle. These feed BFS/DFS/UF.
