How to Use This Course

Start with the Mental Models

If you come from EE, begin with Mental Models to bridge your hardware intuition to software thinking. Then learn the Algorithm Patterns before attempting any coding problems.

EE Analogies Throughout

Every concept is explained with EE analogies — circuits, buses, protocols, signal processing. Your hardware background is an asset, not a gap.

Pattern Recognition Before Coding

The biggest interview failure mode is not recognizing the pattern. Train classification separately from coding using the pattern trainer (python main.py --train).

CLI Quick Reference

# Offline course
python main.py --catalog --verbose             # Full track catalog
python main.py --quiz --topic dsa              # Quiz + tutor on miss
python main.py --drill --pattern bfs           # Generate a problem
python main.py --drill-check gen_bfs_123       # Grade it
python main.py --tutor --topic dp --wrong "..." --right "..."
python main.py --progress                      # SRS / lesson progress

# Pattern study
python main.py --patterns                      # All 21 patterns
python main.py --pattern sliding_window        # Deep dive
python main.py --decision-tree                 # Selection flowchart
python main.py --train                         # Classification trainer

# Coding assessment bank
python main.py --list                          # List all problems
python main.py --generate                      # Create templates
python main.py --run dp_01                     # Test one solution
python main.py --report                        # Full gap analysis
