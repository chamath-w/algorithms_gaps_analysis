Rules

Rule 1: Do not skip days

If you miss a day, do it the next day. Do not jump ahead.

Rule 2: Time-box exercises

If you are stuck on a problem for more than the allotted time, read the hints, then read the solution, then re-implement from memory. Understanding > stubbornness.

Rule 3: Write everything down

Keep a journal (physical notebook or text file). Each day has a "Journal" prompt — answer it in 1-3 sentences.

Rule 4: Read actively

When a guide says "Read section X", take notes. Write down what surprises you or what you disagree with.

Rule 5: Run the code

When the guide says to run a command, actually run it. Do not just read the output.
