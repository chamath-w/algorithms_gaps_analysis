Computer Architecture

How software meets silicon. This should feel like homecoming for an EE — we connect it to the abstractions compilers and OSes assume.

ISA & assembly view

Instruction Set Architecture: registers, ops, addressing, calling convention (who saves what), endianness. High-level variables live in registers or stack slots.

EE bridge

ISA is the “pinout + protocol” between software and the microarchitecture. Microarch can change (pipeline depth, cache) without changing the contract.

Pipelines & hazards

  • Structural: two stages need same hardware.
  • Data: instruction needs result not written back yet → forwarding / stall.
  • Control: branch outcome unknown → predict / flush.

Caches & locality

Cache lines (typically 64B), associativity, hit/miss. Temporal vs spatial locality. False sharing: two cores write different variables on the same line → coherence ping-pong.

Staff performance tip

Big-O ignores the memory hierarchy. Row-major traversal, struct packing, and avoiding false sharing often beat micro-optimizations.

Virtual memory

Pages, page tables, TLB. Page fault = OS loads page. Isolation: each process believes it owns a contiguous address space.
