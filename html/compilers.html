Lex & parse

Lexer: character stream → tokens. Parser: tokens → AST (recursive descent is the practical skill). Ambiguity and precedence matter. 

// recursive descent sketch
function parseExpr() {
  let left = parseTerm();
  while (match('+') || match('-')) {
    const op = previous();
    const right = parseTerm();
    left = new Binary(left, op, right);
  }
  return left;
}

Types & semantics

Static vs dynamic typing. Soundness: well-typed programs don’t get stuck (ideal). Rust ownership = static aliasing discipline; Python = dynamic with runtime checks.

IR & codegen

Intermediate Representation enables optimization independent of source/ISA. SSA (Static Single Assignment): each name assigned once — simplifies dataflow. Codegen respects calling conventions from Architecture.

Runtimes

GC vs manual/RAII/ownership. Green threads vs OS threads. JIT vs AOT. Knowing the runtime explains production perf and memory profiles.
