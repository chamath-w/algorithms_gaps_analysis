Practice Arena

A coached session, not a problem dump. The system hands you a puzzle, makes you commit to a plan, reviews your attempt, and teaches the specific gap it finds — escalating until you clear the bar. Full CPython in the browser (Pyodide). No network after vendoring.

The coached loop
  1. Start a session — it picks your weakest patterns as targets.
  2. Micro-drill — one question to confirm you know the move for this pattern.
  3. Plan gate — write your approach and commit to time/space complexity before the editor unlocks. You then see the canonical plan and the invariant.
  4. Code and Run — the coach diffs your output and classifies the gap.
  5. Escalating coaching on repeat failures: diagnose-it-yourself → targeted hint → micro-lesson → guided repair.
  6. Repeat until satisfactory — a pattern clears at 2 clean solves in a row (first Run passes, no hints, no reveals). Then the session moves to the next target and ends with a gap report.
Coached vs free play

Coached is on by default. Uncheck it in the toolbar for free play: pick any pattern, no plan gate, no session bar — the old drill-and-diff behaviour with Deliberate, Skeleton and Interview modes intact.

How to open

Online (recommended): GitHub Pages — Practice Arena — works in Safari on iPhone and desktop browsers. No install, no local server.

First visit: wait until the toolbar shows Python ready (Pyodide loads ~15 MB; can take 1–2 minutes on cellular). Then tap Start session in the coached panel.

iPhone shortcut: Share → Add to Home Screen for one-tap access. Progress stays in Safari for this site.

Offline / flight mode: while online, open Home and use Prepare for flight to cache the site. Or clone the repo and run python scripts/serve_course.py → http://127.0.0.1:8765/practice.html (do not open via file://).

Running code on phone or tablet

Keyboard shortcuts are not available in mobile browsers. Use the Run button under the REPL scratchpad and the Run tests button under the solution editor — not Ctrl/Cmd+Enter.
