Practice Arena

Visual + do-first drills: micro-quiz → code → run → diff feedback + model trace, with a text coach under the REPL. Full CPython in the browser (Pyodide). No network after vendoring.

How to use

1) Answer the micro-drill (unlocks editor) → 2) Code (Skeleton + Tab for next model line) → 3) Run tests → read the coach + expected/got diff → 4) Replay model trace if you miss. Deliberate mode keeps a pattern until 3 correct in a row.

How to open (WASM needs a local server)

Do not open this file via file://. From the repo root: 

python scripts/serve_course.py
# opens http://127.0.0.1:8765/practice.html

Offline: python scripts/vendor_pyodide.py once (if html/vendor/pyodide/ is missing).
